# 🦷 Clínica Odontológica

Sistema web de gestão e agendamento de consultas odontológicas.

## 📋 Sobre o Projeto

Plataforma desenvolvida para modernizar o atendimento de clínicas odontológicas, centralizando o agendamento de consultas e a apresentação de serviços em um sistema web responsivo.

## ⚙️ Funcionalidades

- ✅ Apresentação de serviços especializados
- ✅ Agendamento de consultas online
- ✅ Design responsivo (mobile e desktop)
- ✅ Integração com banco de dados via PHP

## 🛠️ Tecnologias Utilizadas

- HTML
- CSS
- PHP
- MySQL
